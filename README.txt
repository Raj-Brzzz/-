A LITTLE NOTE FOR YOU ♡

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Or simply double-click index.html to open it in your browser.

HOW TO PERSONALIZE
- Open script.js and edit the text inside the appreciationMessage backticks.
- In index.html, change "Hey, you." or the footer text if you want.
- In style.css, the colors near the top are controlled by CSS variables.

NOTES
- No framework or installation is required.
- Google Fonts are used when internet is available; fallback fonts work offline.
- This is a static website. It does not collect or send anyone's data.
